# shareway-api-gateway

API gateway of ShareWay: the single entry point in front of the
[monolith](https://github.com/FundaTechPeru/shareway-monolith) and, as the Strangler Fig migration
advances, of the services extracted from it.

Node.js 22 · Express 5 · TypeScript (strict) · Google TypeScript Style (gts).

```bash
npm install
npm run check   # lint, type check and tests
```
